# Pitch Tracker

A live repository of every stock pitch Newbrook Capital receives from idea dinners, idea zooms, idea calls and
similar idea-sharing events — for Joe Flaum, TMT-focused. Static site on GitHub Pages (served from `docs/` on
`main`), updated by a daily Claude Code routine that reads the **AI@newbrookcapital.com** shared mailbox.
The full routine prompt lives in `ROUTINE-PROMPT.md`.

**The mailbox is AI@newbrookcapital.com.** Every Outlook search must pass `mailboxOwnerEmail = AI@newbrookcapital.com`,
and every read must use the `uri` exactly as search returned it, including `?owner=AI%40newbrookcapital.com`.
That mailbox only goes back to 2026-07-21; the 2026-01-01 → 2026-07-22 backfill was read from jf@'s own mailbox.

## Layout

```
data/ideas.json          canonical store (events + ideas, full text). Written only by tools/merge_ideas.py
docs/data/ideas.json     what the page loads (no pitch text). Derived by merge_ideas.py
docs/data/pitches.json   pitch text + event notes, lazy-loaded by the detail view. Derived by merge_ideas.py
docs/data/prices.json    prices, performance, sector, market cap. Written ONLY by the "Update prices" Action
docs/index.html          static page; never regenerated by a run
tools/merge_ideas.py     canonical merge + identity. All de-duplication rules live here
tools/update_prices.py   Yahoo Finance fetch + performance math (runs in the Action; Yahoo is blocked in Claude's sandbox)
tools/test_tools.py      tests for both
```

## Rules for any run

- **Never hand-edit or hand-merge the store.** Always: `NOW_ISO=$(TZ=America/New_York date +%Y-%m-%dT%H:%M:%S%:z) python3 tools/merge_ideas.py --add new_ideas.json`.
  Identity changes belong in `tools/merge_ideas.py` with a test, never in a run transcript.
- **Runs never touch `docs/data/prices.json` or `docs/index.html`.** Page design changes are a separate, deliberate edit.
- **Never commit an empty or partial store over a good one.** If Outlook fails, stop and report.
- **Nothing is ever deleted.** Corrections are an incoming idea with `"correct": true`; the retired id lands in `aka`.
- Publish by pushing straight to `main`, then verify the checksum of `docs/data/ideas.json` on `origin/main`.
  The prices Action also pushes to `main` (only `prices.json`), so a non-fast-forward is resolved with `git pull --rebase`.

## Input schema (`new_ideas.json`)

`{"events": [...], "ideas": [...]}`. Events carry a file-local `key`; ideas point at it with `ev_key`.
The tool assigns `id`, `aka`, `seen`, `upd`.

events: `key` `d` (YYYY-MM-DD, day presented) `name` `host` `series` (grouping, e.g. "MCH Idea Dinner",
"DeMatteo TMT Dinner", "DeMatteo Investor Idea", "Newbrook dinner notes") `fmt` (Dinner|Zoom|Call|Conference|Discussion)
`focus` `loc` `presenters` `summary` `notes` (event-level write-up, verbatim) `src`

ideas: `ev_key` `d` `tk` (as quoted; Bloomberg style for non-US, e.g. "000150 KS") `yf` (Yahoo symbol; "" if private)
`co` (optional; page falls back to the Yahoo name) `dir` (Long|Short) `tag` ("dirty double", "pair: long X / short Y", "lightning round") `pr` (presenter;
"Undisclosed" / "Participant") `fm` (firm) `th` (one-liner ≤160 chars) `pt` `px_ref` (number) `mcap_ref` `cat`
`pitch` (full text, paragraphs separated by blank lines) `ext` (stable external id, e.g. DeMatteo link token)
`src` ("Sender <addr> | Subject | received YYYY-MM-DD") `correct` (true only for corrections)

Yahoo suffixes: KS→.KS KQ→.KQ LN→.L GR/GY→.DE FP→.PA NA→.AS SM→.MC IM→.MI SW/SE→.SW SS→.ST DC→.CO NO→.OL
FH→.HE JP/JT→.T HK→.HK CN/CT→.TO AU→.AX TT→.TW IN/IS→.NS. US class shares use "-" (BRK-B).

## Identity

event id = `d-hostslug(14)-nameslug(48)`; idea id = `<event id>--<tickerslug>-<l|s>`.
An incoming idea matches by `ext`, then id/aka, then (event, ticker, direction). An `ext` match with an earlier
date moves the idea to that earlier date/event (first time pitched wins); if that move lands on an existing
idea, the two fold (retired id and ext go to `aka`). A copy in a catch-all series (`CATCHALL_SERIES`, today
"DeMatteo Investor Idea") folds into the same host's pitch of the same ticker and direction within 3 days under
a named event. Events left with no ideas and no notes are dropped. The store covers pitches from 2026-01-01 on.

## Performance conventions (tools/update_prices.py, shown in the page footer)

Pitch price = close on pitch date (last close before it if shut). T+30/T+90 = first close on/after +30/+90
calendar days. Adjusted closes for returns; sign-flipped for shorts; α vs SPY over the same window.
Market cap in USD = shares × price × FX; cap at pitch scales today's cap by the price change.
